# Wellnest Pro — Health Care & Meal Planner

A polished, responsive wellness and meal planning web app made with HTML, CSS, and vanilla JavaScript.

## Included features
- Modern login/demo welcome screen and responsive dashboard
- Daily health monitor: weight, sleep, movement, water intake, notes, and mood
- Daily records stored by date in browser localStorage
- Meal planner with vegetarian/non-vegetarian filters and meal selections
- Approximate calorie total for selected meal ideas
- Progress summaries, a 7-day water/movement chart, and check-in history
- Editable daily targets for water, sleep, and movement
- Export health history as a CSV spreadsheet
- Light/dark theme toggle
- Mobile navigation and responsive layouts

## Run the project
1. Extract the ZIP.
2. Open the `health-meal-planner-pro` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Enter a name and any demo password of at least four characters.

No Node.js, npm, or backend is required.

## Important
- Login is only a front-end demo and is not secure authentication. Do not enter a real password.
- Data is saved in this browser's localStorage and is not synchronized to other devices.
- Meal and calorie values are approximate examples, not medical or personalized dietary advice.
- This application is a wellness organizer, not a medical diagnosis or treatment tool.
